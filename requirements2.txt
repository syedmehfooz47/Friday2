# INSTALLATION NOTES:

# 1. Create virtual environment: python -m venv .venv
# 2. Activate: .venv\Scripts\activate (Windows) or source .venv/bin/activate (Linux/Mac)
# 3. Upgrade pip: pip install --upgrade pip
# 4. Install all packages: pip install -r requirements2.txt
# 5. For Windows users: Install Microsoft Office for document conversion features
# 6. For pdf2image: Download Poppler binaries and add to PATH
# 7. For CairoSVG: Install GTK+ runtime on Windows
# 8. PyAudio on Windows: May require manual installation of wheel file
#
# OPTIONAL SYSTEM DEPENDENCIES:
# - Poppler (for pdf2image): https://github.com/oschwartz10612/poppler-windows
# - GTK+ Runtime (for CairoSVG): https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer
# - Microsoft Office (for office document conversion)
# - PortAudio (for PyAudio, usually included in PyAudio wheels)
#
# NOTE: This file installs LATEST versions of all packages.
